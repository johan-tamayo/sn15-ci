# Race-14 Forged Field Suite (`s14_r14`, 45 Open Tasks, `w-forge-s14-r14`)

## 1. Overview & World Mechanics
- **Pack Path**: `~/sn15-ops/suites/graded30_v2/packs/s14_r14` (`pack_id: p-forge-s14-r14`, `world_id: w-forge-s14-r14`), built by `tools/forge/r14_forge/build_s14_r14.py` from `runs/r14_forge/` (lane `r14forge1`).
- **Corpus Provenance**: all `9,945` released Race-14 open episodes (`223` agents x `2` validators x `45` open tasks; `1,958` passing order episodes across `26` tasks, `19` 0-pass tasks with exact stated + hidden clauses).
- **100% Verbatim `request_text`**: every task carries the verbatim shopper request recovered from the released transcripts (`runs/r14_forge/r14_verbatim_requests.json`; one field agent echoes it in five `buyerAsk` chunks).
- **Truth**: `lita` = in-stock catalog items matching stated + hidden clauses UNION every passing field cart on that line; `reza` = stated-only fits UNION lita; `jufuli` calibrated on passing / `not_the_best_option` carts (cheapest tasks); one answer slot per event bitmask.
- **Catalog**: all `7,341` cards seen in the episodes (`4,265` full pages with `product_properties`, `985` pointer cards with `item_good_to_know`).
- **Task mix**: 1L `20` / 2L `8` / 3L `15` / 4L `2`; hidden slots on `40/45` tasks (67 slots), reply-by-reference on `5/45`, pointer chains on `12/45`, mid-episode notices on `4/45`.
- **7 Race-14 Tools (`tools.json`)**: `itemsSeek(phrase | productShelf, strategy text|browse, pageNumberNum 1..2)` -> `{num_hits_number, page_follow, search_items[11]}`; `weigh(targetRefs 1..2)` -> full cards (`call_problem` on 3+ refs); `pageDescribe(idCode)` -> `{blurb_body, brand, department, id, item_good_to_know, item_list_price, product_name_text, product_properties, ready, seller}`; `buyerAsk(words)` -> `{value}` (4 messages, 5th -> `budget_exceeded`); `holdToCart(item, lineNumber = absolute pieces 0..4)` -> `{went_through}`; `itemsBag()` -> `{basket_lines, cart_total_cost}`; `taskClose(lookupWay order|none, explanation)` -> `{went_through}` / `{call_problem: "Your basket is empty right now."}`.
- **Store Notices**: budget moves and requirement drops ride on the NEXT tool observation as `{"bujiri": <obs>, "lobofe": [<sentence>]}` (triggers `after_reveal` / `first_add`); events not yet fired at the first `taskClose` refuse it (`{"observation": {"went_through": true}, "refusal": [...]}`) and the episode continues (the last `taskClose` decides).
- **Persona**: 12 reveal frames, 10 nopref, 10 DNU (`dnu_default` on 17 multi-line tasks), 10 bundle-refusal strings drawn on non-slot questions at the task's field share (`bezifa.bundle_pct`).
- **Process rules**: reference chains (`answer.refs`) opened via `pageDescribe` / `weigh` + hidden needs (`answer.needs`) via `buyerAsk`; `process_rules = []`.
- **Known limits (FAIL rows on the fidelity card)**: cross-line `fits` constraints and conditional rules of the 4L tasks are recorded in `suite_index.json` (`spec.extra.fits` / `conditional`) but NOT graded; three pointer chains end on a card no field agent opened (`t-833f1251d3` pack type, `t-d38d81ac25` battery type, `t-f4408f1b8e` color): the slot stays a graded need without a value filter.
