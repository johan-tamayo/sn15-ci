Shapes are asserted by the oracle.
- **Store Notices**: events ride on the NEXT tool observation as `{"harafo": <obs>, "jezudo": [<sentence>]}`; an event not yet fired at the first commit refuses it (`{"observation": {"applied": true}, "refusal": [...]}`) and the episode continues.

## Search / browse fit (`runs/forge3/HANDOVER.md`, 2026-11-06)
- `lookupItems` reproduces the live store's search as fitted on every recorded race-15 search (`runs/forge3/fit_r15.py`): lowercase, `( ) , - . : ; |` split (`'` `&` `/` `"` kept), dedup, AND over the FIRST 8 words, BM25 k1 1.5 / b 0.0 (score tiers in id order), top 1000, 7 per page.
- `world/index/jasu.json`: k1 1.5, b 0.0, `analyzer` lucene_uax29 (Lucene EnglishAnalyzer replica: UAX#29 tokens, possessive strip, 33 Lucene stop words, Lucene Porter), `df_override` (live-scale document frequencies: exact from single-term live searches, shelf-coverage estimate otherwise) with `n_docs` = the live corpus size.
- `brand` (index-only field; the cards show `maker` / `merchant`) carries live-evidence search words for 2708 pointer cards (listings no field agent opened: facts unknown; the words every live page proves they contain, with the term frequency the live ranking tier implies).
- `listRange` reports the live shelf size as `count` (constant per shelf in the field); pages 1..7 were already identical.

## Question credit fit (lane forge4, applied by the builder from `/Users/administrator/sn15-ops/runs/forge4/credit_model.json`; `--no-credit-fit` rebuilds without it)
- `askBuyer`: a question the reader scores for one or more of the task's subjects is credited the way the live labeler chain credits it (fitted on every released race-15 and race-14 question, the same table on both races): the subject the shopper reads is the first hit by position among the question's names; a need at the first name is credited ~100%, at a later name k2: first 0.96 / last 0.76, k3: first 1.00 / second 0.62 / last 0.60, k4-5: first 0.99 / second 0.60 / middle 0.48 / last 0.23, k6+: first 1.00 / second 0.76 / middle 0.48 / last 0.06; multi-line shelf context factors own 1.00 / none 0.53 / another line's 0.03; a decoy read before the need blocks the credit with 0.30; a second need after a read need is never credited; an uncredited question gets the task's non-slot reply (did-not-understand on `dnu_default` tasks, no-preference otherwise).
- The decision is one draw per message from the episode PRNG seed (`credit_seed`, drawn at `start` after the shopper setup) and the message index, so a replay of the same episode nonce repeats it.
